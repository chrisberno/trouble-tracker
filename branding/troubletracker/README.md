# branding/troubletracker

TroubleTracker brand assets: logos, color palette, copy, and landing-page assets for the TroubleTracker wedge product.

This folder contains the TroubleTracker visual identity — the branded surface that TroubleTracker tenants and their customers see. It is distinct from any specific deployment's branding overrides (those live in `deployments/{client-id}/`).

Phase 4 (Productize) will fill this folder as part of the GTM funnel build. Per the Roadmap, Phase 4 opens only after three concrete bridge adapters are proven in production.
